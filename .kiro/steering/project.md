# 项目约定

- 本仓库用于存放「名画 Rap 系列」的所有项目资料和工作成果，新的作品和修改都提交到这里。
- 每个作品一个目录（如 `星空独白/`），目录内包含：
  - `lyrics.md`：最新版歌词（旧版本靠 git 历史追溯，不另存副本）
  - `suno.md`：Suno 风格提示词 + 可直接粘贴的带标签歌词
  - `storyboard.md`：分镜表和 AI 画面提示词
- 新作品要在根目录 `README.md` 的作品表里登记。
- 文档用中文写；AI 画面/音乐提示词用英文。
- 歌词风格：短句（约 4+3 字）、每句押韵、两句一组双押，史实要准确。
- 先定故事线（主题 + 情感线 + 起承转合），再写词；删减时要检查情感线和首尾呼应是否还完整。
- 时长控制在 60～90 秒（约 24 行歌词），观众看得完，生成成本也低。
- 给 Suno 的歌词里不放圆括号（喊词、和声），只用方括号结构标签。
