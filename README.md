# 名画 Rap 系列

用 AI 把名画和画家的故事做成说唱短视频（抖音向）。

## 作品

| 作品 | 画家 / 名画 | 状态 |
|---|---|---|
| [星空独白](./星空独白/) | 梵高《星月夜》 | 歌词第六版（短版，约 75～80 秒，以提奥为情感线），待用 Suno 生成 |

## 计划

- 名画 Cypher：星空、蒙娜丽莎、呐喊、戴珍珠耳环的少女等轮流上场

## 制作流程

1. 写词（AI 起稿 + 人工打磨押韵）
2. Suno / 海绵音乐生成歌曲
3. 原画图生视频 + 自画像对口型（可灵 / 即梦 / OmniHuman）
4. 剪映卡点、字幕、调色
