# 《星空独白》分镜表（短版，约 75 秒）

## 统一风格后缀

每个画面提示词后面都加上：

```
Van Gogh style, thick impasto oil brushstrokes, swirling textures, vivid blue and yellow, cinematic
```

## 原画素材（均已进入公有领域）

《星月夜》、包扎耳朵的自画像（1889）、《阿尔勒的卧室》、《麦田群鸦》

## 实操提醒

- 对口型前把音频按段落切成 10～15 秒的小段
- 割耳、枪响只用暗示画面，避免抖音限流
- 字幕用手写风格字体，颜色取星空蓝和向日葵黄
